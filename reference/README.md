# NOJÎN Golden Reference

این پوشه مرجع رسمی بصری و تعاملی NOJÎN است.

## مرجع اصلی

- `reference/nozhin_pwa_demo.html`
- این فایل Golden Reference نسخه مبنای UI/UX و رفتارهای نمایشی NOJÎN است.
- در فازهای بعدی، هر اختلاف UI/UX باید ابتدا با این فایل مقایسه شود.
- تغییر مستقیم این فایل بدون تصمیم مشخص محصول مجاز نیست.

## اصل مرجع

ترتیب تصمیم‌گیری در صورت ابهام:

1. نیاز صریح جدید کاربر
2. Golden Reference همین پوشه
3. مستندات NOJÎN
4. در نبود اطلاعات کافی، ساده‌ترین پیاده‌سازی سازگار با معماری

Golden Reference به معنی الزام به کپی معماری HTML نیست؛ محصول نهایی Native Flutter خواهد بود و ظاهر، تعامل و رفتار قابل مشاهده این فایل باید به‌صورت Native بازسازی شود.
