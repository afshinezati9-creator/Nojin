# Phase 10 — Rich Editor

## هدف

افزودن ویرایشگر بلوکی آفلاین برای Notes بدون وابستگی به Media Engine و بدون شکستن یادداشت‌های متنی قدیمی.

## قابلیت‌های این فاز

- متن ساده
- عنوان
- چک‌لیست
- لیست موردی
- لیست شماره‌دار
- نقل‌قول
- بلوک کد با کپی
- تاریخ شمسی
- جداکننده
- Toggle
- جابه‌جایی و حذف بلوک‌ها
- ذخیره ساختاریافته داخل ستون `notes.content`
- سازگاری خواندن با یادداشت‌های قدیمی که `content` متن خام دارند
- پیش‌نمایش متن ساده در کارت Notes
- استفاده از SVG icon system

## مدل ذخیره‌سازی

ستون موجود `content` همچنان منبع ذخیره است، اما یادداشت‌های Rich با JSON نسخه‌دار ذخیره می‌شوند:

`{ "version": 1, "blocks": [...] }`

بنابراین migration دیتابیس برای این فاز لازم نیست.

## مرز فاز

Media مانند تصویر، ویدئو، صوت و فایل در Phase 11 پیاده‌سازی می‌شود.

## تست محلی

در محیط اجرای فعلی Flutter SDK در دسترس نیست؛ بنابراین `flutter analyze` و `flutter test` ادعا نشده‌اند. تست codec در پروژه اضافه شده و باید روی Windows/Chrome یا Android محلی اجرا شود.
