# Phase 02 — Iranian Core

## هدف

ساخت لایه پایه ایران‌محور مستقل از UI برای استفاده در همه Featureهای آینده.

## انجام‌شده

- IranNumber: تبدیل رقم فارسی/انگلیسی و جداکننده هزارگان فارسی.
- IranMoney: تومان به‌عنوان پیش‌فرض و تبدیل تومان/ریال.
- IranPhone: نرمال‌سازی شماره ایرانی، اعتبارسنجی و فرمت بین‌المللی.
- IranBank: اعتبارسنجی کارت با Luhn و شبا با MOD-97.
- IranDate: تبدیل میلادی/جلالی و نمایش با ارقام فارسی.
- IranCalendar: قرارداد پایه تقویم جلالی/میلادی/قمری.
- IranLocalization: locale، RTL، نام روزها و ماه‌های جلالی.
- IranHolidayProvider: تعطیلات ثابت شمسی قابل توسعه.
- تست واحد برای هسته‌های عدد، پول، تلفن، بانک و تاریخ.
- حذف Workflow موقت CI؛ تست واقعی طبق فرآیند محصول در محیط توسعه انجام می‌شود.

## محدودیت عمدی

این فاز دیتاست کامل تعطیلات قمری/مناسبت‌های متغیر و موتور کامل تقویم را پیاده نمی‌کند؛ آن بخش طبق Roadmap در Phase 20 تکمیل خواهد شد.

## قانون استفاده

Featureهای بعدی نباید منطق تکراری برای اعداد فارسی، پول، تلفن، کارت، شبا یا تبدیل تاریخ بسازند؛ باید از lib/core/iran/ استفاده کنند.
