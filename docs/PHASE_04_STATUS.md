# Phase 04 — App Shell

هدف: ایجاد قاب اصلی ناوبری NOJÎN بدون پیاده‌سازی منطق دامنه‌ها.

## انجام‌شده
- NojinAppShell بر پایه ShellRoute
- ناوبری مشترک بین صفحات
- موبایل: NavigationBar
- نمایشگرهای عریض: NavigationRail
- آستانه adaptive فعلی: 800px
- AppBar مرکزی با عنوان نوژین و جستجو
- صفحه خانه responsive
- استفاده از Design System فاز 03
- حفظ RTL از لایه App

## محدودیت
منطق جستجو، داشبورد، نوتیفیکیشن و navigation اختصاصی featureها در این فاز پیاده نمی‌شود.
