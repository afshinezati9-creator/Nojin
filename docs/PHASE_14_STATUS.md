# Phase 14 — Finance Dashboard

Phase 14 adds a real-data finance dashboard over the existing Phase 12/13 database.

- KPI: income, expense, and net for Toman.
- Separate Rial summary when Rial transactions exist.
- Top expenses with relative bars.
- Latest 8 transactions with account names.
- Archived accounts are excluded from dashboard aggregation.
- Responsive mobile/tablet/desktop layout.
- Loading, empty, and error states.
- No database migration was required.
- Repository tests cover aggregation and archived-account exclusion.

Flutter SDK is not available in this execution environment, so flutter test/analyze were not run. Local Windows verification remains required.
