# Phase 13 — Iranian Finance

## وضعیت

Phase 13 تکمیل شد و Finance Foundation را برای داده‌ها و conventions مالی ایران گسترش می‌دهد.

## پیاده‌سازی

- پشتیبانی صریح از تومان و ریال در حساب‌ها.
- جلوگیری از جمع‌زدن تومان و ریال در یک موجودی کل؛ موجودی‌ها بر اساس واحد پول جدا نمایش داده می‌شوند.
- اطلاعات حساب بانکی: نام بانک، شماره حساب، شماره کارت ۱۶ رقمی و شماره شبا.
- استفاده از IranBank برای نرمال‌سازی و اعتبارسنجی کارت و شبا.
- پشتیبانی از ارقام فارسی در ورود مبلغ و شماره‌ها.
- نمایش و قالب‌بندی ایرانی مبالغ با IranMoney و IranNumber.
- نمایش اطلاعات بانکی در جزئیات حساب و امکان کپی آن‌ها.
- امکان ویرایش نام، نوع و اطلاعات بانکی حساب.
- اطلاعات بانکی برای حساب‌های غیر بانکی ذخیره نمی‌شود.
- مهاجرت دیتابیس از schema version 2 به version 3 بدون شکستن حساب‌های قبلی.
- تست برای ساخت حساب بانکی، اعتبارسنجی کارت/شبا، تومان/ریال و migration.

## تست محلی مورد نیاز

Flutter SDK در محیط اجرای این جلسه در دسترس نیست؛ بنابراین flutter analyze و flutter test از اینجا اجرا نشدند.

پس از دریافت main در Windows:

```powershell
flutter pub get
flutter test
flutter analyze
flutter run -d chrome
```

سناریوی UI:
1. ساخت حساب بانکی تومان.
2. ورود شماره کارت معتبر و شبا.
3. مشاهده و کپی اطلاعات بانکی.
4. ساخت حساب ریالی و اطمینان از جدا بودن موجودی آن.
5. ثبت درآمد/هزینه در هر دو نوع حساب.
6. ویرایش اطلاعات بانکی.
