# NOJÎN — Phase 09 Status: Notes Foundation

## هدف
پیاده‌سازی هسته واقعی Notes روی معماری فازهای ۰۷ و ۰۸، بدون ورود به Rich Editor یا Media Engine.

## تحویل این فاز
- مدل دامنه Note و دسته‌های پایه: ایده‌ها، کار، شخصی، مطالعه، عمومی
- Repository مستقل برای CRUD و query روی جدول notes
- جستجو در عنوان و محتوا
- فیلتر دسته، سنجاق‌شده و بایگانی
- مرتب‌سازی بر اساس آخرین تغییر، ایجاد و عنوان
- Riverpod state/controller مخصوص Notes
- اتصال صفحه Notes به دیتابیس محلی
- نمایش تاریخ جلالی در UI و ذخیره زمان به UTC
- عملیات ساخت، ویرایش، سنجاق، بایگانی و حذف

## خارج از محدوده
- Rich Editor و بلوک‌های پیشرفته → Phase 10
- تصویر/ویدئو/صوت و مدیریت فایل → Phase 11
- همگام‌سازی ابری → فازهای بعدی
- جستجوی سراسری کل برنامه → Phase 26

## اصل داده
جدول notes از Phase 07 استفاده می‌شود و در این فاز migration جدیدی لازم نیست.

## تست
تست repository با دیتابیس SQLite در حافظه برای CRUD، filter و search اضافه شده است.
تست Flutter در محیط توسعه محلی Windows/Chrome باید پس از دریافت این فاز اجرا شود؛ این محیط اجرای Flutter SDK در اختیار ندارد.
